    Controls

    Left mouse button
    Uses the current tool. Pick tools from the Tools menu.
    Right or middle mouse button, drag
    Pans the view.
    Mouse wheel
    Zooms in and out.
    Shift
    Changes what many tools do: rotate instead of move, repel instead of attract, cool instead of heat, and so on. The status bar describes the current tool.
    Keyboard
    Space pauses, Enter steps one frame while paused, + and - zoom, Home resets the view.
    NPCs
    Use the NPC tools to add people and furniture, move them, remove them and turn them around. Drag a rectangle with Move, Remove or Turn Around to select several at once.
    Switchboard
    Ships with electrical parts get a draggable switchboard for switches, engine controls and gauges. Toggle it from the Options menu.

    Ship building and saving ships.
